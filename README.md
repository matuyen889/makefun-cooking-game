Kitchen Station Rush is a complete, fast-paced arcade cooking game built for make.fun's "Make the best cooking game" competition.

## Features
- **Kitchen Counter Stations**: Prep and chopping board, dual sizzle grill, central dish assembly station, and brass service bell pass.
- **Dynamic Order Board**: Live customer tickets with patience countdown timer bars, combo multipliers, and tip calculations.
- **Dish Mid-Assembly**: Layer-by-layer visual burger stack rendering on ceramic dinner plates.
- **Audio Synthesizer**: Procedural Web Audio API sound effects for knife chopping, grill sizzling, order bell chimes, and victory fanfares.
- **Offline & Zero Network Requests**: 100% self-contained static HTML5 canvas game.

## How to Play
Open `game/index.html` in desktop Google Chrome.
- **1-7**: Quick pick ingredients to assemble on plate
- **C**: Slice tomatoes on the prep cutting board
- **Space**: Ring order bell and serve completed dishes
